Visión general

Objetivo del proyecto

La weather-api es una aplicación web que permite consultar el clima actual de una ciudad de manera rápida y visual. El usuario ingresa el nombre de la ubicación, la aplicación consume una API de clima y muestra información relevante como temperatura, sensación térmica, humedad, velocidad del viento y estado del cielo.

  • Diseño visual atractivo y profesional.
  • Adaptación a dispositivos móviles.
  • Estructura clara para que los clientes tengan una buena primera impresión.
